# Маленький музей

Домашнее приложение для рисунков и поделок двух сыновей, Кирилла и Марка.

## Задача

Дети рисуют и мастерят каждый день. Листы теряются, поделки ломаются, а фото в галерее телефона смешиваются с остальными снимками. Нужно было место, где каждая работа сохранится аккуратно, с автором и датой, и где их приятно пересматривать.

## Решение

Веб-приложение (PWA), которое ставится на домашний экран iPhone и работает как обычное приложение.

- **Рисунок:** родитель фотографирует лист на столе, приложение само находит края листа, выравнивает перспективу и вешает рисунок в «музей» в рамке.
- **Фигурка, вырезанная ножницами:** приложение отделяет её от стола по контуру и сохраняет с прозрачным фоном.
- **Поделка:** фото с четырёх сторон; заложена возможность собрать из них 3D-модель (через Meshy).
- У каждой работы есть автор, дата, название, заметка («что рассказал автор») и коллекция.

## Экраны

- **Музей** — карусель работ в разных рамках: деревянная, на скотче, на булавке, паспарту. Рамка выбирается по id работы, поэтому у каждой работы она своя и не меняется.
- **Коллекции** — цветные «кармашки» с работами внутри.
- **Скан** — съёмка рисунка или поделки.
- **История** — лента по месяцам с фильтром по ребёнку.
- **Настройки** — художники и их цвета.

## Вырезка без нейросетей

Фон убирается прямо на телефоне, без серверов и ML-моделей:

1. **Цвета стола.** По пикселям у краёв кадра k-means находит несколько цветов стола: светлые и тёмные волокна дерева. Предметы у края кадра (стопка бумаги) отбрасываются.
2. **Заливка фона.** Фон «растекается» от краёв кадра по похожим цветам, пока не встретит резкую границу — край бумаги. Поэтому кожа персонажа, похожая по оттенку на светлое дерево, не пропадает.
3. **Контур.** Берётся самая крупная область, убирается «ворс» по краю и щепки стола.
4. **Результат.** Маска сглаживается и накладывается на фото в полном размере; на выходе PNG с прозрачностью.

Если на фото прямоугольный лист, а не фигурка, приложение само выбирает режим «Лист»: сравнивает, насколько найденная фигура совпадает с четырёхугольником по её углам. Оба режима можно переключить вручную, а для вырезки есть ползунок «бережнее — смелее».

## Дизайн

- **Шрифты:** Literata — для слоганов и названий работ (книжный, «музейный» характер), Unbounded в облегчённых начертаниях — для интерфейса.
- **Цвета:** акцентный зелёный #417B5A и шесть пастельных оттенков для коллекций и детей.
- **Референс:** приложения-альбомы с карточками-кармашками и рамками на стене.

## Технологии

React, TypeScript, Vite, PWA; Supabase (база, приватное хранилище файлов, доступ только для почт семьи через RLS); Edge Function для 3D через Meshy; model-viewer для просмотра 3D и AR; GitHub Pages.
